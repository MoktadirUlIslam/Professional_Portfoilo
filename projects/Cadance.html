⏱️ Cadance - Study in Rhythm

  • Tech Stack: Flutter, Dart, Firebase (Authentication, Firestore & Cloud Messaging), Provider (State Management), Android Studio
  • Project Type: Mobile Application
  • Status: Production Ready ✅
  • GitHub: View Project

Cadance is a comprehensive productivity application built using the Pomodoro Technique to help users manage time effectively. The app combines a focus timer, task management, event calendar, and progress tracking all in one seamless experience.

🚀 Key Features

  • 🎯 Focus Timer - Customizable Pomodoro timer with multiple presets (25/5, 30/5, 52/17, 90/20) and focus lock mode to prevent distractions
  • 📋 Task Manager - Organize tasks by type (Classes, Assignments, Lab Reports, Exams, Class Tests) with priority levels, deadlines, and reminders
  • 📅 Event Calendar - Manage events with categories, recurrence (daily/weekly/monthly/yearly), and smart notifications
  • 📊 Progress Analytics - Track focus time, task completion rates, streaks, and productivity insights with visual charts
  • 🏆 Badge System - Earn achievements for consistency, focus streaks, and milestone completions
  • 🌓 Dark Mode - Full light/dark theme support with system preference detection
  • 🔔 Smart Notifications - Local and push notifications for task reminders, event alerts, and break warnings

🛠️ Technical Architecture

  • Frontend: Flutter with Provider for state management
  • Backend: Firebase Firestore for real-time database
  • Authentication: Firebase Auth with email/password
  • Notifications: Firebase Cloud Messaging + Flutter Local Notifications
  • Offline Support: Firestore persistence for offline access
  • Analytics: Firebase Analytics for user behavior tracking

💡 Key Implementations

  • Phone lock integration during focus sessions to prevent distractions
  • Forced return overlay for break time management
  • Real-time task and event synchronization across devices
  • Recurring events with infinite repetition (daily/weekly/monthly/yearly)
  • Multiple reminder system with customizable intervals
  • Activity tracking with streak calculation and contribution graphs
  • Productivity score with focus efficiency and consistency metrics

📈 Stats & Achievements

  • Total Focus Minutes: Tracked and displayed in dashboard
  • Task Completion Rate: Percentage of tasks completed
  • Current Streak: Consecutive days of activity
  • Longest Streak: Personal best record
  • Badges: 15+ achievements to unlock
  • Productivity Score: AI-powered efficiency rating

🔒 Security Features

  • Secure Firebase Authentication
  • Cloud Firestore Security Rules
  • Data encryption at rest
  • Session management and auto-logout

Built with ❤️ using Flutter - Available on Android and iOS platforms.
